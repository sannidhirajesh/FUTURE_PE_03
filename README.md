# FUTURE_PE_03 – AI SEO Blog & Content Cluster Generator

## Internship Track
Prompt Engineering (PE)

## Project Overview
This project demonstrates how AI prompts can be used to generate SEO-friendly blog content, organize content clusters, and create local SEO materials for a fictional coffee shop called Bean & Bloom Café.

## Objectives
- Generate SEO-friendly blog topics and outlines.
- Create readable, keyword-focused blog content.
- Build a content cluster with a pillar page and supporting articles.
- Develop local SEO content for a business.

## Tools Used
- ChatGPT
- GitHub
- Markdown

## Repository Contents
- `prompts.md` – Prompts used for SEO content generation.
- `blog_content.md` – SEO-friendly coffee blog.
- `content_cluster.md` – Pillar page and supporting topic structure.
- `local_seo.md` – Local SEO content and keyword ideas.

## Project Workflow
1. Identify the business and target audience.
2. Develop prompts for SEO content generation.
3. Generate a blog article with SEO metadata.
4. Organize related topics into a content cluster.
5. Create local SEO content using location placeholders.

## Expected Outcome
A structured SEO content package that demonstrates how prompt engineering can support blog writing, content planning, and local SEO.

## Disclaimer
Bean & Bloom Café is a fictional business created for this project. The content is intended for demonstration and educational purposes.
