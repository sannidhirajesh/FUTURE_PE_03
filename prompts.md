# AI SEO Blog & Content Cluster Generator

## Project: Bean & Bloom Café

### Prompt 1: SEO Blog Topic Generator
Generate 10 SEO-friendly blog topics for Bean & Bloom Café, a cozy coffee shop. Focus on coffee lovers, students, and working professionals. Include relevant keywords and search intent.

### Prompt 2: SEO Blog Outline Generator
Create a detailed SEO-friendly blog outline for the topic "Best Coffee Drinks to Try at a Cozy Café."

Include:
- SEO-friendly title
- Meta description
- H1 heading
- H2 and H3 headings
- Primary and secondary keywords
- Search intent

### Prompt 3: SEO Blog Writer
Write a helpful, engaging, SEO-optimized blog titled "Best Coffee Drinks to Try at a Cozy Café."

Requirements:
- Use clear and simple language.
- Include relevant keywords naturally.
- Use H1, H2, and H3 headings.
- Include an introduction and conclusion.
- Add a call to action encouraging readers to visit Bean & Bloom Café.
- Avoid keyword stuffing.

### Prompt 4: Content Cluster Generator
Create a content cluster for the main topic "Coffee Guide."

Include:
- One pillar page topic
- Five supporting blog topics
- Primary keywords for each topic
- Suggested internal links between the articles

### Prompt 5: Local SEO Content Generator
Generate local SEO content for Bean & Bloom Café.

Include:
- Local SEO title
- Meta description
- Local keywords
- Google Business Profile description
- A call to action

Use placeholders for the city and location instead of inventing business details.
